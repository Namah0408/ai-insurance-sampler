# AI Insurance Sampler

AI-powered life insurance sampling and risk assessment system.

## Project Goal

The system is designed to assist life insurance samplers by analysing proposal information, documents, verification results, financial information, insurance exposure and approved underwriting guidelines.

## Architecture

- Frontend: React + Vite + Tailwind CSS
- Backend: FastAPI + Python
- Database: PostgreSQL
- AI orchestration: LangGraph
- LLM: Gemini or another approved enterprise LLM
- RAG: Vector database
- ML: Optional risk/fraud models
- Integrations: OmniDocs, Karza/Perfios, IIB
- Deployment: Docker
