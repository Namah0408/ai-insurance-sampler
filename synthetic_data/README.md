# Synthetic Data

This directory contains completely synthetic data for development
and testing of the AI Insurance Sampler.

The data does not represent real customers.

The synthetic cases are used to test:

- document checks
- KYC checks
- PAN/Aadhaar matching
- BAWC checks
- financial checks
- existing policy checks
- application consistency checks
- risk scoring
- risk flag generation

The rules and thresholds currently used by the prototype are
demonstration rules only.

They must not be treated as actual insurance underwriting rules.
